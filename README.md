# Source code for past assignments
## Pharmacy Management System
Programmed in Python, a text file-based database was utilized to allow the listing and purchasing of pharmaceutical products by pharmacist and customer respectively.
## Tuition Centre Management Application
A tuition management application with graphical user interface was programmed in C# using Object-Oriented Programming concepts with extensions to SQL database to store all appropriate information.
## Data Analysis on Employee Dataset
Analysis was done on dataset about employment using R programming language to extract and uncover trends that may be crucial for enterprises.
## Hostel Management Application
By applying the full extent of Object-Oriented Programming with Java, a Hostel Management Application was developed. The graphical user interface was programmed rather than using the drag and drop provided by NetBeans IDE.
